# Python Mini Projects Collection

This repository contains beginner-friendly Python projects created for learning and practice purposes.  
Each project demonstrates basic Python concepts, logic building, and problem-solving skills.

---

## Projects Included

### 1. QR Code Generator
Generate QR codes for any text or URL using Python.

##Features
- Converts text/URLs into QR codes
- Saves QR code as an image
- Simple and easy to use

#Technologies Used
- Python
- qrcode library
- PIL (Pillow)

---

### 2. Digital Clock
A simple digital clock built using Python that displays real-time hours, minutes, and seconds.

## Features
- Live time display
- User-friendly interface
- Real-time updates

# Technologies Used
- Python
- Tkinter

---

### 3. Pattern Programs
Collection of different star and number pattern programs using loops.

##Patterns Included
- Pyramid Pattern
- Inverted Pyramid
- Right Triangle
- Number Patterns
- Diamond Pattern

# Concepts Used
- Loops
- Nested loops
- Conditional statements

---

### 4. Rent Calculator
A basic rent expense calculator that divides rent and other expenses among roommates.

##Features
- Calculates total expenses
- Splits rent equally
- Easy input system

# Concepts Used
- User input
- Arithmetic operations
- Variables
